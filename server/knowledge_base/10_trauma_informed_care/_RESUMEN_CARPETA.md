# Cuidado Informado por Trauma (Trauma-Informed Care)

## Resumen de la Carpeta

Esta carpeta contiene documentación sobre el enfoque de Cuidado Informado por Trauma aplicado al tratamiento de trastornos por uso de sustancias.

### Artículos incluidos:
1. **trauma_informed_care_SUD.md** — Marco conceptual, principios y aplicación práctica del TIC en adicciones

### Cuándo usar esta información:
- Cuando el usuario revela experiencias traumáticas (ACEs, violencia, abuso)
- Para adaptar el tono y las intervenciones cuando hay señales de trauma
- Para evitar re-traumatización durante las conversaciones
- Para fundamentar la conexión entre trauma y uso de sustancias
